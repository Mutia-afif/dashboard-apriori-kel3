# 🛒 Market Basket Analysis & Rekomendasi Bundling (Kelompok 3)

Project ini adalah aplikasi web interaktif berbasis Streamlit untuk menemukan pola pembelian obat/suplemen menggunakan **Algoritma Apriori**. Dibuat untuk memenuhi tugas mata kuliah Data Mining 2.

## Fitur Utama
- **Dashboard EDA (Eksplorasi Data):** Melihat ringkasan data transaksi.
- **Pengaturan Parameter Interaktif:** Menyesuaikan nilai *Minimum Support* dan *Minimum Confidence* secara langsung.
- **Simulator Rekomendasi Bundling:** Mencari tahu produk apa yang cocok dibundling dengan produk pilihan pelanggan.
- **Visualisasi Network Graph:** Memetakan jaringan hubungan antar produk.

## Cara Menjalankan Secara Lokal
1. Clone repository ini ke komputermu.
2. Install library yang dibutuhkan: `pip install -r requirements.txt`
3. Jalankan aplikasi: `streamlit run app.py`
